# antenna_linear

Настольное приложение на Python для расчёта линейной антенны (линейной апертуры). Решает две задачи:

- **Прямая задача** — по заданному амплитудно-фазовому распределению (АФР) на апертуре рассчитывает диаграмму направленности (ДН) и её характеристики.
- **Обратная задача** — по требуемой ДН восстанавливает АФР на апертуре методом наименьших квадратов.

## Возможности

### Прямая задача

- Параметры антенны: длина `L`, длина волны `λ`, число точек апертуры `N`, число углов `M`.
- Амплитудное распределение: равномерное, косинусное, гауссово или произвольное (формула `f(x)`).
- Фазовое распределение: нулевое, линейное (параметр в рад/м) или произвольное (формула `φ(x)`).
- Графики амплитуды и фазы на апертуре, ДН в дБ (углы от -90° до 90°).
- Характеристики ДН: направление максимума, ширина главного лепестка по уровню -3 дБ, уровень боковых лепестков.

### Обратная задача

- Требуемая ДН: `|cos(θ)|^n`, гауссова или произвольная формула `D(θ)`.
- Восстановление комплексного АФР (амплитуда и фаза) на апертуре.
- Сравнение требуемой и синтезированной ДН на одном графике.
- Среднеквадратичная ошибка синтеза (RMS).

### Общее

- Две вкладки интерфейса: «Прямая задача» и «Обратная задача».
- Ввод собственных формул с ограниченным набором функций.
- Экспорт результатов в CSV.

## Технологический стек

- **Язык:** Python 3.8+
- **Интерфейс:** Tkinter (`ttk`, `ScrolledText`)
- **Вычисления:** NumPy
- **Графики:** Matplotlib (бэкенд TkAgg)
- **Поиск боковых лепестков:** SciPy (`find_peaks`), необязательная зависимость
- **Экспорт:** модуль `csv` из стандартной библиотеки
- **Контроль версий:** Git / GitHub (ветки `main`, `develop`)

## Установка и запуск

```bash
pip install numpy matplotlib scipy
python antenna_linear.py
```

Tkinter входит в стандартную поставку Python. На некоторых дистрибутивах Linux его нужно установить отдельно (`sudo apt install python3-tk`). Без SciPy приложение работает, но уровень боковых лепестков определяется упрощённо, по второму максимуму.

## Как пользоваться

1. Откройте нужную вкладку.
2. Введите параметры антенны и выберите тип распределения.
3. Нажмите «Рассчитать» (прямая задача) или «Синтезировать» (обратная задача).
4. Посмотрите графики и характеристики. Нажмите «Сохранить результаты», чтобы выгрузить данные в CSV.

### Пользовательские формулы

| Поле | Доступные переменные | Доступные функции |
|---|---|---|
| Амплитуда `f(x)` и фаза `φ(x)` | `x`, `L` | `sin`, `cos`, `exp`, `sqrt`, `abs`, `pi` |
| Требуемая ДН `D(θ)` | `theta` (рад), `theta_deg` (град), `z = k·L·sin(θ)`, `L`, `k` | `sin`, `cos`, `exp`, `sqrt`, `abs`, `pi` |

Формула должна возвращать массив той же длины, что и аргумент. Примеры: `cos(pi*x/L)`, `exp(-(2*x/L)**2)`, `abs(cos(theta))**2`.

Для обратной задачи формулу нужно выбрать в списке типов ДН значением `custom_formula`. Для прямой задачи заполненная формула имеет приоритет над выбранным типом распределения.

## Формат CSV

- Прямая задача: блок `x, amp, phase` и блок `theta (deg), pattern_db, pattern_lin`.
- Обратная задача: блок `x, amp, phase` и блок `theta (deg), pattern_target, pattern_synth`.
